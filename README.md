# VacancyFind 🇱🇰

**Discover companies in Sri Lanka. Explore career opportunities. Find your next step.**

VacancyFind is a desktop application that brings together career websites and company links from across Sri Lanka, making it easier for graduates, job seekers, and professionals to discover organizations they can apply to.

The project initially focuses on opportunities relevant to **Mechatronics, Electronics, and Telecommunication graduates and professionals**, with the goal of making the job search process a little easier.

## 💡 Why I Built This

I started collecting company names and career website links when I was applying for internships.

During that process, I realized how difficult it was to know all the companies that might offer relevant opportunities. Finding one opportunity could take considerable searching, and sometimes I would discover a much better opportunity much later simply because I did not know that the company existed.

I wanted to make it easier to explore companies, discover their career pages, and keep track of potential places to apply.

**VacancyFind grew out of that personal experience.** It is my attempt to organize the information I collected and make it useful to other students, graduates, and professionals facing the same challenge.

## 🚀 Features

- **Categorized career links:** Explore companies and organizations grouped into categories.
- **Direct access to career pages:** Open a company's careers website directly from the application.
- **Open multiple websites:** Use the *Open All Sites* functionality to open the links in a category or collection, where supported by the application.
- **Desktop application:** Access the collection through a graphical interface instead of maintaining a list of bookmarks manually.
- **Cross-platform builds:** Download versions for Windows, macOS, and Linux as they become available.

VacancyFind is a directory of career links, not a recruitment platform. Applications and vacancies are managed by the respective companies on their own websites.

## 💻 Download VacancyFind

**[Download the latest release from GitHub](https://github.com/DasDNS/VacancyFind/releases/latest)**

Choose the download that matches your operating system and processor architecture.

| Platform | Download | Architecture |
|---|---|---|
| Windows | `VacancyFind-Windows-x64.zip` | 64-bit Windows |
| macOS | `VacancyFind-macOS-arm64.zip` | Apple Silicon Macs (M-series) |
| macOS | `VacancyFind-macOS-x64.zip` | Intel-based Macs |
| Linux | `VacancyFind-Linux-x86_64.AppImage` | 64-bit x86 Linux |

The release page is the central location for published application downloads. If a platform's file is not listed there, that build has not yet been published as a release asset.

### Windows

1. Download `VacancyFind-Windows-x64.zip` from the [Releases page](https://github.com/DasDNS/VacancyFind/releases/latest).
2. Extract the ZIP file.
3. Run `VacancyFind.exe`.

### macOS

1. Download the ZIP matching your Mac's processor.
   - **Apple Silicon:** M-series Macs.
   - **Intel:** Macs with Intel processors.
2. Extract the ZIP file.
3. Open `VacancyFind.app`.

The application is currently distributed without Apple code signing and notarization. macOS may therefore show a security warning when you first open it.

### Linux

1. Download `VacancyFind-Linux-x86_64.AppImage` if it is available in the release.
2. Open a terminal in the download directory.
3. Make the file executable:

   ```bash
   chmod +x VacancyFind-Linux-x86_64.AppImage
   ```

4. Run the application:

   ```bash
   ./VacancyFind-Linux-x86_64.AppImage
   ```

The AppImage is intended for compatible 64-bit x86 Linux systems. Other CPU architectures require their own builds.

## 🧭 How the Application Works

VacancyFind presents a collection of companies and their career website links through a desktop graphical interface.

1. **Choose a category** to explore relevant companies.
2. **Browse the listed organizations** and identify companies that match your interests.
3. **Open a career website** to view the company's recruitment information and available vacancies.

Company websites and vacancies can change over time, so always check the official website for current information and application requirements.

## 🛠️ Technology and Development

VacancyFind is a Python desktop application built with **PySide6**, which provides its graphical user interface.

The project uses Git and GitHub for source-code management and GitHub Actions to automate application builds for supported platforms.

### Built with AI

An important part of this project is that it was built entirely using **AI assistance through ChatGPT and prompts**.

I am sharing the project openly so that others can explore it, use it, and potentially contribute to its improvement.
